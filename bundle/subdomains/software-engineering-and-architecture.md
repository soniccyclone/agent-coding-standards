# Software Engineering & Architecture

## Definition
How systems get structured at a scale beyond a single function or module —
methodology, large-system architecture, the discipline of keeping a system
coherent as it grows. Sits closer to the implementation-mapping layer than
Foundations does, since it's usually reasoning about composing already-chosen
mechanisms rather than deriving new primitives.
