# Cognitive Load

## Definition
How much state, context, or hidden coupling a reader must hold in working
memory simultaneously to correctly predict what a construct does. Distinct
from primitive count: a construct built from few primitives can still impose
high cognitive load if those primitives compose in ways that require tracking
a lot of simultaneous context (e.g. deep mutual recursion, or state threaded
implicitly through many call sites).
