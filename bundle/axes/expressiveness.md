# Expressiveness

## Definition
How closely the written form of a construct can track the intent behind it —
whether stating a computation requires indirection, boilerplate, or
translation loss, or whether the code can sit close to the thought that
produced it. Distinct from primitive count: a formalism can be minimal in
primitives while still being awkward to express a given idea in, or rich in
built-in vocabulary while staying easy to write against.
