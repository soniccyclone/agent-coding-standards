# Verifiability

## Definition
How tractable it is to formally establish properties of a construct —
correctness, termination, invariants held across state changes — as opposed
to gaining confidence only through testing or runtime observation. A
construct scores high here when its structure gives a proof system (or a
disciplined human) purchase: small state space, explicit pre/post-conditions,
composable reasoning. This is the axis Formal Methods & Verification as a
subdomain is organized around.
