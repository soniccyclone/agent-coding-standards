# Put the permitted operations next to the data they touch, and give up language power until the compiler can enforce it

**Lesson:** An access convention that lives in a programmer's head, or in a comment, or in a review habit, is not a property of the program. The move that makes it one is syntactic colocation: the declaration of a data structure and the complete set of operations permitted on it become a single unit of text, so that the intended discipline is written down in a form a translator can read. Doing this converts a whole family of coordination questions from behavioral to structural. Whether two activities can collide over a variable stops being a question about execution order and becomes a question about which module the variable was declared in, which is decidable before anything runs.

The hard part is not inventing the notation but accepting its price, and this is the part most designers flinch from. A compiler can only decide whether the discipline is obeyed if it can tell, by inspecting a piece of text, which data that text can reach. Unrestricted pointers destroy that ability, because a reference handed across a module boundary is an unaudited path to someone else's state. Uncontrolled side effects destroy it too, because you can no longer tell a construct's inputs from its outputs by looking. So the language has to lose features — real, useful features that competent programmers miss — for the guarantee to exist at all. Anyone unwilling to pay that gets a convention rather than a check, and conventions do not hold under maintenance by people who were not in the room.

What a programmer does differently is treat "which code may touch this state" as a design decision to be stated in the source and mechanically verified, not as a fact to be reconstructed later by grep and hope. There is a second benefit that shows up only after the discipline is in place. Once each piece of state has exactly one module with jurisdiction over it, protecting the system stops requiring runtime enforcement — the hardware mechanisms and dynamic checks that normally police access become largely unnecessary, because the property they were policing is already established. Safety and speed turn out to be on the same side of this decision, which is not the usual arrangement.
