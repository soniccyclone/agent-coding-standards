description: Girard's doctoral thesis, written in French, which proves strong normalization for a system of higher-order arithmetic and in doing so introduces System F (the polymorphic/second-order lambda calculus) as a proof-theoretic tool rather than a programming construct — a discovery made independently of, and slightly before, John Reynolds's language-design route to the same system. The proof extends Girard's "candidats de réductibilité" (reducibility candidates) method, generalizing Tait's earlier normalization technique to handle quantification over types. It's the origin point for polymorphic type theory as later adopted throughout statically typed functional languages.
