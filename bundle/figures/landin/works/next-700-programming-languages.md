description: Landin argues that the ALGOL-family languages of the day are best understood as surface variants of a single underlying core, ISWIM, built on Church's lambda calculus plus a small set of imperative extensions. This "reduce syntax to semantic core" move became the standard way language designers and semanticists relate new languages to each other.
