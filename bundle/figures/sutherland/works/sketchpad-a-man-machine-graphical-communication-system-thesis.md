description: Sutherland's 1963 MIT PhD dissertation describing Sketchpad, a real-time interactive drawing system built on Lincoln Laboratory's TX-2 computer. The full dissertation runs considerably longer than the condensed conference paper published the same year, with more detail on the constraint-satisfaction machinery and system architecture.
