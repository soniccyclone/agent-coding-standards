description: Backus's 1977 Turing Award lecture argues that conventional languages are stuck imitating the von Neumann machine's word-at-a-time, state-mutating fetch-execute cycle, and that this inheritance limits how programs can be built and reasoned about. He proposes function-level programming instead: whole programs assembled from a small fixed set of combining forms (composition, construction, etc.) applied to functions, with no named variables or explicit sequencing. The lecture includes an algebra of laws for transforming these programs, aimed at making large-scale program construction and proof as tractable as ordinary algebra.
