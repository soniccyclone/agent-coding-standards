description: The original 1957 conference paper introducing FORTRAN, written by Backus and the twelve-person IBM team that built it, presented shortly after the system shipped for the IBM 704. It lays out the language's mathematical-expression notation and the compiler's approach to translating that notation into machine code the team believed could rival hand-coded assembly in efficiency. As the first public technical description of a working high-level-language compiler, it is the primary source for how the FORTRAN project's engineers understood their own design.
