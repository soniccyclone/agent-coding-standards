# Alan Turing

**Dates:** 1912-1954. British mathematician, Cambridge/Bletchley Park/Manchester.

## Why a candidate
Defined computability via an idealized machine with a minimal instruction set (read/write/move on an infinite tape) rather than a syntactic calculus — the mechanism-first lineage this subdomain explicitly retains alongside Church's. Per project-state.md §2 (frozen): not rejected, placed at the implementation-mapping layer relative to Church's design-thought primacy — this stub exists for bundle consistency, layer placement already settled.
