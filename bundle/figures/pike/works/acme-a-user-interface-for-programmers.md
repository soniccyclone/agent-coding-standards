description: Describes Acme, Pike's combined window system, shell, and editor built around treating the screen itself as a namespace of mutable text. Instead of separate windows-plus-terminal-plus-editor tooling, Acme exposes its internal state as a Plan-9-style file server and lets any text on screen be executed as a command or loaded as a file via mouse chording, collapsing several traditionally separate programs into one consistent text-manipulation model. It's the clearest demonstration of Plan 9's file-and-namespace philosophy applied to the programmer's own interface rather than the OS.
