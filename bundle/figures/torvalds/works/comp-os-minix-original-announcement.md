# Original Usenet Announcement, comp.os.minix

**Venue/year:** Usenet, comp.os.minix newsgroup, August 25, 1991 (thread subject reads "Re: What would you like to see most in minix?" in this archive's threading, but the quoted body is Torvalds' original announcement — "Hello everybody out there using minix - I'm doing a (free) operating system...").
**Source:** https://groups.google.com/g/comp.os.minix/c/dlNtH7RRrGA/m/SwRavCzVE7gJ — live, Google Groups' Usenet archive; third-party rehost of the original comp.os.minix post (Usenet itself has no single canonical host, so this counts as the citable public copy rather than a self-archived original).
