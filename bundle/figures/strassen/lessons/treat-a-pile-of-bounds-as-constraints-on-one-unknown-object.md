# Treat a pile of separate bounds as constraints on one unknown object, and track the object instead

**Lesson:** A field working on a hard quantity accumulates results the way sediment accumulates: a bound from one construction, a slightly better bound from another, a bound for a differently-shaped variant of the problem, each published as a separate achievement and each superseding its predecessor by a decimal place. The reframing that pays is to ask what all of them are statements *about*. If the theory has a single unknown object — a region, a body, a set of admissible parameter values — then each of those scalar results is a constraint carving that region down, and typically each is exactly one halfspace containing it. Once you see them that way, the list turns into geometry. Bounds that looked independent are revealed as supporting hyperplanes of the same body, and some are revealed as redundant, implied by others already in hand. You also see immediately what each result cost you: a construction may naturally yield a whole convex constraint, of which the published scalar bound is only one supporting halfspace, so the customary way of stating the result was throwing information away every time it was applied.

The reframing also changes the objective. Improving a constant is an unbounded task with no terminal state; determining the body is a definite question that can be answered, and the constant falls out of it as the extreme value of some linear functional. That makes the interesting conjectures structural rather than numeric — is the region convex, is it connected, is it symmetric under the problem's symmetries — and a structural fact about the region can be worth more than any single numeric improvement because it yields a whole family of inequalities at once rather than one. It also tells you where the remaining uncertainty actually lives, which a list of best-known-constants cannot.

Two practical habits fall out. First, bracket from both sides: cheap invariants — dimension counts, trivial constructions, degenerate instances — usually hand you specific points that must lie inside the region, and crude general arguments hand you a coarse outer region, so before doing any hard work you know the unknown sits between an explicit inner set and an explicit outer one. Every subsequent result narrows a gap you can see. Second, restate the existing literature in the new coordinates as an exercise, because that is how you find out whether the framing is right: if every known result translates into a constraint on the object and nothing is left over, the object is the correct one to be studying, and if something resists translation, that residue is where the framing is still incomplete.

**Source:** [The Asymptotic Spectrum of Tensors](../works/the-asymptotic-spectrum-of-tensors.md) — section 4: a coarse outer estimate places the logarithmic spectrum of general matrix multiplication inside a truncated pyramid while cheap format-derived gauge points are shown to lie inside it; the conclusion of the classical summation theorem is identified as merely a supporting halfspace of the convex constraint set that the underlying construction actually yields, demonstrated on a concrete instance; each published bound on an exponent of rectangular matrix multiplication is proved equivalent to the statement that the spectrum lies in a particular halfspace; and the paper notes that the existing literature on those exponents can accordingly be rephrased entirely in terms of the spectrum, with convexity of the region raised as the structural conjecture that would subsume the numeric results.
