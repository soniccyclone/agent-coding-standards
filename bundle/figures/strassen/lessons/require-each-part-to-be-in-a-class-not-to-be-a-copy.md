# Require each part to belong to a class, not to be a copy of a fixed one

**Lesson:** The natural way to build a big regular object out of a small one is to take the product: a coarse pattern, with an identical copy of the small object sitting in every cell the pattern marks. Every theorem you prove about the product then depends on that identity, and the theorem stops applying the moment you meet a structure in the wild whose cells are all *the same kind of thing* but not literally the same thing. The fix is to weaken the hypothesis at exactly one point. Demand that each cell's equivalence class lie in a permitted set of classes, and that cells outside the pattern be empty — but say nothing about which representative of the class occupies each cell. Different cells may then differ arbitrarily, so long as each is individually of the right kind. The class of objects satisfying the weaker hypothesis is enormously larger, it contains all the products as a special case, and the arguments you cared about survive because they only ever consulted the class.

The reason the arguments survive is worth stating on its own, because it is the general condition for this relaxation being safe. Every step of the reasoning must be one that consults a cell only through the invariant that the class fixes — its cost, its capabilities, what it can be transformed into — never through a coordinate of a particular representative. If a step reaches past the class into the representative, the relaxation breaks there and you have to find another route. So the exercise of relaxing "identical copy" to "member of a class" is really an audit of your own proof for illegitimate dependence on incidental detail, which is why the relaxed version is usually the clearer version even when you had no need for the extra generality.

The payoff is a two-level structure where the levels are analyzed by different tools. The coarse pattern is a small object in its own right, and whatever you can prove about it — that a large regular sub-pattern can be extracted from it, say — applies wholesale, because the pattern is what carries the global bookkeeping. The cells are handled locally, by whatever facts hold of their class. Neither level needs to know how the other works. This is exactly the division of labor that lets an argument scale: global structure reasoned about globally, local structure reasoned about only up to interface, and the fact that no cell is required to match any other is what makes real structures qualify. The same shape recurs whenever a component contract is specified behaviorally rather than by naming an implementation — the contract is the class, and refusing to look past it is what buys the generality.

**Source:** [Relative Bilinear Complexity and Matrix Multiplication](../works/relative-bilinear-complexity-and-matrix-multiplication.md) — section 7's definition of a tensor whose blocks, under a chosen block decomposition, are each required only to have equivalence class in a permitted set while blocks off the pattern's support are null; the paper's explicit note that this generalizes the tensor product because distinct blocks may be arbitrarily different representatives of the same class, so such objects are locally but not globally equivalent to a product; and the two-level argument that follows, where a large regular sub-pattern is extracted from the coarse tensor and each surviving block is then accounted for by the properties of its class.
