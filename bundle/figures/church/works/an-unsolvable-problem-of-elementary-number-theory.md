description: Church defines "effective calculability" formally by identifying it with lambda-definability, then uses that definition to prove there is no algorithm for deciding, given a formula of elementary number theory, whether it is provable. It predates and mathematically parallels Turing's independent 1936 unsolvability result via Turing machines.
