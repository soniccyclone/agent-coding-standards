# A property you must assert separately at every site is a symptom of not being able to quantify over the sites; gain that power and the whole family collapses into a definition

At first order, Church has to install equality by hand. It gets a new symbol, an axiom saying everything equals itself, and then either an axiom schema with an instance for every context or — if the vocabulary is finite — an explicit axiom for each argument position of each operation, asserting that operation by operation, slot by slot, replacing equals leaves things alone. It is a pile of assertions, it grows with the language, and every extension to the language obliges another entry.

At second order the entire pile disappears. Church notes that equality need not be added at all: it can be *defined*, by the observation going back to Leibniz that two things are the same exactly when every property of one is a property of the other. One definition, no new symbol, no axioms. Reflexivity, symmetry, transitivity and substitutivity then come out as ordinary theorems proved in a few lines each, and the same definition scales upward to sameness between things other than individuals in the higher calculi.

What changed is not that equality got easier. What changed is that the language acquired the ability to say "every property," and the pile of assertions was never really about equality — it was a hand-expansion of a quantifier the language could not express. Each per-operation congruence axiom was one instance of "properties do not distinguish equals," written out because there was no way to state the general claim. Given the general claim, the instances become consequences rather than commitments. This is also why the difference matters more than an axiom schema would suggest: a schema is a pattern in the metalanguage, so its instances are individually available but the pattern itself is not something the system can reason about. Internalizing the quantification turns the pattern into a single object inside the theory, which can then be used, proved about, and substituted into like anything else.

The diagnostic transfers cleanly, and it is one of the more useful smells to be able to name. Whenever you find a rule enforced by repetition — a null check at every call site, a permission assertion at the top of every handler, a logging or tracing preamble in each method, a "remember to also update X" note attached to every place that touches Y, a lint rule that exists because the language cannot express the constraint — the repetition is measuring an expressive gap. The right response is rarely more discipline about the repetition, and often not a code generator that writes the instances for you either, since that keeps them as instances. It is to find the construct that lets the claim be stated once and consumed generically: a type that makes the invalid state unrepresentable, a wrapper that owns the boundary so callers cannot skip it, a trait or interface whose signature is where the obligation lives.

Church's example also shows the honest cost. The collapse was bought with second-order quantification, a genuinely stronger and more expensive setting, and the rest of the chapter is about what that strength costs elsewhere. So the move is not free and the question is not whether to always take it. The question is whether the repeated assertions have grown numerous enough, and coupled tightly enough to future extensions, that paying for the quantifier is cheaper than continuing to enumerate.

**Source:** [Introduction to Mathematical Logic](../works/introduction-to-mathematical-logic.md) — the opening of the section on equality in the functional calculus of second order, where Church observes that unlike the first-order case, no equality constant and no equality axioms need be added, because equality is definable by the Leibniz condition that a property holding of one individual holds of the other; the reflexive, commutative, transitive and substitutivity laws are then derived as theorems, and the same definition extends to sameness between entities of other types in the higher calculi.
