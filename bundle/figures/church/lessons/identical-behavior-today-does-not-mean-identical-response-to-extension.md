# Two systems that behave identically today can respond differently to being extended, and the difference is invisible to every test of current behavior

Church has just proved two formulations of the propositional calculus equivalent in the strongest sense available: exactly the same theorems, with the substitution rule that one has and the other lacks recoverable as a derived rule in the one that lacks it. Then he adds a remark that is easy to miss and hard to unsee once noticed. The system built from axiom schemata is not complete in any of the three senses he defined, while the one it replaced is complete in all three. A bare propositional variable can be adjoined to it as an axiom without producing a single theorem that was not already a theorem. And he names the cause: without the substitution rule, the system's rules can no longer tell a propositional variable from a propositional constant, so it admits a wider class of interpretations than the original — which shows up nowhere in the theorems, because the theorems were fixed by the equivalence.

The structural point is that completeness in his sense is not a statement about what the system proves. It is a statement about what happens when you add something to it, and two systems can agree on every current output while disagreeing on that. The substitution rule was carrying a constraint — variables must be substitutable, therefore variables are not constants — that no theorem exercises and that governs everything downstream of an extension. Moving that constraint from the rules into the shape of the axioms preserved every consequence and dropped the constraint itself, which is a change with no present-tense symptom.

This is the exact shape of a large class of engineering regressions and it defeats the usual defenses. A refactor replaces a runtime check with a construction that makes the current inputs satisfy it anyway; every test passes, because the tests exercise current inputs, and the next input class arrives unchecked. A validation rule is dropped because no live data violates it; the schema's meaning quietly widened, and nothing detects the first record that exploits the width. Two ORM configurations produce identical queries for today's model and diverge the moment a nullable column is added. A dependency-injection wiring is inlined; behavior is identical until someone needs a second implementation. A permissive default is introduced under a flag that is currently never set. In every case the change is verified against the present behavior, the present behavior is genuinely unchanged, and what was actually modified is the system's response to a future edit that nobody has made yet.

The consequence for practice is uncomfortable but simple. A test suite measures the theorem set. It cannot measure how the system will react to being extended, because that reaction is a property of the rules and the tests only see the consequences. So when you replace a mechanism with an equivalent one, the equivalence you have established is the weak one, and the question left over is what the old mechanism constrained that the new one does not. Church answers that question about his own construction in a footnote, unprompted, having just proved the equivalence he was after. That is the habit worth copying: after showing two arrangements agree, ask what each one rules out, and check whether the exclusions agree too. Where they do not, you have not refactored — you have changed the system in a way that will be discovered by whoever extends it, at a distance from anything that looks related.

**Source:** [Introduction to Mathematical Logic](../works/introduction-to-mathematical-logic.md) — the footnote to the section on formulations employing axiom schemata, observing that despite the schema-based system having exactly the same theorems as the system with a substitution rule, and despite substitution being a derived rule of it, it is not complete in any of the three senses given earlier, since a propositional variable can be adjoined to it as an axiom without producing any new theorem — which Church connects to its admitting a wider class of interpretations, its rules no longer sufficing to distinguish propositional variables from propositional constants.
