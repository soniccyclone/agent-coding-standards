# Non-interference is a theorem about which paths a result can travel, not a corollary of having kept the pieces separate

Church lays out a family of propositional calculi built by accretion: a positive system with no negation at all, then the intuitionistic system obtained by adding negation and two axioms about it, then the minimal system obtained by adding a different negation axiom instead. Because each added axiom mentions the added connective, it looks obvious that adding negation cannot change what the negation-free fragment proves. It is not obvious, and Church does not treat it as obvious. He cites a result of Wajsberg establishing that any theorem of the larger system can be proved using only the two implication axioms plus those axioms whose connectives actually appear in the theorem — and only from that does the consequence follow, that the negation-free theorems of the extended systems are exactly the theorems of the positive one, and the implication-only theorems of all three coincide.

The gap between the plausible reading and the proved one is the whole lesson. Nothing in the shape of the axiom list prevents a derivation of a negation-free formula from wandering through a negation axiom, introducing a negation in an intermediate step, and eliminating it later. Whether such detours can always be removed is a question about the space of derivations, not about how the axioms are arranged on the page, and it is settled by a normalization argument that has to be carried out. Had that argument failed, the extended system would have proved things about implication that the smaller system could not, and the "separate" negation axioms would have been silently load-bearing for results that never mention negation.

The engineering version of this belief is everywhere and it is almost never checked. A feature is added behind a flag and declared safe because the flag is off. A new module is introduced and declared non-invasive because it lives in its own package. A field is added to a schema and declared backward compatible because old readers ignore it. A plugin system is declared isolating because plugins are loaded separately. In every case the claim is that behavior in the absence of the new thing is unchanged, and in every case the claim is about executions rather than about file layout. The detours are real and familiar: a shared cache the new module warms, a global registry it registers into at import time, a serialization format whose framing changed to make room, a query planner that now sees a new index and chooses differently for old queries, an error taxonomy that grew a case some old handler falls through. None of these appear in the module boundary and all of them break non-interference.

So the practice is to state the non-interference claim as a proposition and then find the argument that makes it true rather than the layout that makes it look true. The strongest arguments have the shape Wajsberg's has: an exhaustive account of the ways a result could be reached, plus a demonstration that any path through the new material can be rewritten into one that avoids it. Engineering rarely affords a proof, but the same reasoning is available cheaply — enumerate the shared resources both sides can touch, and for each one either show the new code cannot reach it or show that its reachable states are unchanged. Where the enumeration is impossible because the shared surface is unbounded, that is the finding: you do not have a modular extension, you have two things in separate files. And the diagnostic is worth applying in reverse too. If removing the new feature entirely would change any observable behavior of the old paths, the separation you believed in was never there, whatever the directory structure says.

**Source:** [Introduction to Mathematical Logic](../works/introduction-to-mathematical-logic.md) — the section on partial systems of the propositional calculus, describing the positive, intuitionistic, and minimal calculi as extensions of a common core, and citing Wajsberg's result that any theorem of the intuitionistic system is provable from its first two axioms together with only those axioms containing the connectives actually appearing in the theorem, from which Church derives that the negation-free theorems of the intuitionistic and minimal calculi coincide with those of the positive calculus and that the purely implicational theorems of all three coincide with those of the positive implicational calculus.
