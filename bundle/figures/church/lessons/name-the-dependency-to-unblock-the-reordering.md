# When an inner thing's dependence on an outer thing blocks a reordering, invent a name for the dependence; the reordering then costs you substitutability, not correctness of the answer

Church wants formulas in a very particular shape: all the existential quantifiers first, all the universal ones after. This is not achievable by rearranging, because a universal quantifier standing before an existential one is a genuinely different claim from the reverse, and the ordering carries the whole content. His procedure gets there anyway, and the move is to introduce a function symbol that does not appear in the original formula at all — a fresh name whose arguments are exactly the variables the inner quantifier was allowed to depend on. Once the dependence has a name, it is no longer implicit in the nesting, and the nesting can be rearranged. Each application of the step converts one blocking universal quantifier and pushes it to the back; the number of universals sitting ahead of an existential strictly falls, so the process ends.

What it costs is stated exactly and is not what you would guess. The result is not equivalent to the original. Church's theorem about it is only that the original is provable if and only if the transformed version is — the two agree on the one bit he intends to compute, and on nothing else. Compare his prenex normalization a few sections earlier, which preserves full equivalence and can therefore be applied to any part of any formula without disturbing the whole. This one cannot. It is a transformation you apply to a complete problem, at the boundary, to answer a specific question; it is not a rewriting you may perform on a subterm, because the transformed thing is genuinely about something the original was not.

Both halves transfer. The first half is a design move that shows up constantly under different names: when nesting is what encodes a dependency and the nesting is in your way, promote the dependency to a value. A callback made explicit as a continuation lets control flow be rearranged. A pending result made explicit as a future lets the computation that produces it move relative to the computation that consumes it. Passing a collaborator in rather than constructing it inside is the same trick — the dependence stops being structural and becomes a parameter, at which point it can be supplied earlier, later, or differently. Materializing an intermediate result under a name lets a pipeline be reordered around it. Adding an explicit sequence number lets messages that relied on arrival order be processed out of order. In each case something implicit in the arrangement acquires a name, and the arrangement becomes free.

The second half is the discipline that keeps the trick from turning into a bug. Ask what relation the rewriting actually preserves, and confine its use to contexts where that relation is enough. A transformation that only agrees on the final answer belongs at the top level, applied once, with the result never substituted back into a larger expression and never handed to a consumer expecting the original's meaning. The characteristic failure is applying an answer-preserving rewrite compositionally: hoisting a query rewrite that is valid for the whole query into a subquery whose result is consumed elsewhere, caching a normalized form that was only ever meant to decide a comparison, or letting a solver's internal reformulation escape into an error message that now names a symbol the user never wrote. The fresh name Church introduces is the tell — a rewriting that had to invent vocabulary is not talking about the same thing anymore, and the invented vocabulary marks precisely the boundary it must not cross.

**Source:** [Introduction to Mathematical Logic](../works/introduction-to-mathematical-logic.md) — the section on Skolem normal form: the reduction procedure that repeatedly replaces a universal quantifier standing before existential ones by introducing a fresh functional variable of the appropriate arity applied to the preceding existentially quantified variables, its termination argument by the strictly decreasing count of universal quantifiers preceding an existential one, and the accompanying metatheorem that the original formula is a theorem if and only if its Skolem normal form is — contrasted with the earlier prenex normalization, whose corresponding result is full provable equivalence.
