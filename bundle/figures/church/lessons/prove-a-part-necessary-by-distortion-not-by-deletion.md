# To prove a part is load-bearing, distort the system rather than delete the part: build a self-map that keeps everything else sound and breaks only the thing in question

Church wants to show that none of the five axioms and none of the six rules of a particular formulation can be dropped. The naive approach — remove one and try to prove the missing results anyway — establishes nothing when it fails, because failure could always be lack of ingenuity. What he does instead is construct, for each component, a systematic rewriting of formulas into formulas. Swap every universal quantifier for an existential one. Rewrite every quantified part into a fixed trivially false shape. Collapse every bound variable to a single fixed variable and drop the quantifier. Delete negation everywhere while replacing one variable by a tautology. Each rewriting is checked against the whole system: it must carry every axiom to a theorem and every rule to a rule that still holds, with exactly one exception, and it must carry some theorem to a non-theorem. That combination is a proof, because anything derivable without the excepted component would have to survive the rewriting, and something demonstrably does not.

The structural point is that the witness is a map from the system into itself, not an external model. Nothing about these rewritings requires a semantics, an interpretation, or a second implementation to compare against. They are distortions of the artifact expressed in the artifact's own vocabulary, and their whole content is: here is a property that everything else preserves and this one thing does not. Each is deliberately targeted; there is no general-purpose distortion, and the one Church needs for the last axiom is a composition of five separate rewritings applied in sequence, because none of the simple ones would isolate it. The component that resists every cheap distortion is the one most entangled with the rest, and the effort of building its witness is the measure of that entanglement.

Read as engineering practice, this is the difference between a deletion test and a mutation test, and mutation is the stronger tool for the same reason. Deleting a component to see whether anything breaks is confounded: other parts of the system compensate, defaults fill in, a second code path covers the case, and you conclude the thing was dead when it was merely shadowed. Distorting the system so that one guarantee is systematically violated while everything else stays intact isolates the guarantee. Flip the sense of a comparison everywhere and see which test notices. Make every cache lookup miss and see whether correctness survives, which tells you whether the cache is an optimization or load-bearing state. Serve every request from one shard and see which invariant fails, which tells you what the partitioning is actually for. Return an empty result from a permission check rather than removing the check, so that failure surfaces as denial rather than as a crash you would have found anyway.

Three habits follow. First, when you cannot demonstrate that something matters, you have not shown that it does not; the burden is to construct the world where its absence is visible, and that construction is real work. Second, design the distortion to preserve everything else — a mutation that breaks five things at once proves nothing about any of them, which is why Church verifies every remaining axiom and rule against each rewriting before drawing a conclusion. Third, treat difficulty of isolation as a finding. When you cannot construct a distortion that breaks one component alone, that component is coupled to the others through some path you have not named, and finding the path teaches you more than the independence result would have.

**Source:** [Introduction to Mathematical Logic](../works/introduction-to-mathematical-logic.md) — the independence section for the finitely-axiomatized formulation of the pure first-order functional calculus, where each axiom and rule is shown independent by exhibiting a transformation on well-formed formulas (interchanging universal and existential quantifiers, replacing quantified parts by a fixed contradiction, replacing bound variables by a single fixed variable, deleting negation while replacing a propositional variable by an implication) that carries every axiom to a theorem and every primitive rule to a primitive or derived rule except the one at issue, while carrying some theorem to a non-theorem; and the final case, where a composite transformation built in several stages is required.
