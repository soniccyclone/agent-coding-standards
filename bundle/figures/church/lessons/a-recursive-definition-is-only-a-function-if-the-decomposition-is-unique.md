# A definition by recursion on structure is only a function if the structure decomposes exactly one way, so unique readability is a proof obligation and not a formatting concern

Before Church can define the value of a formula, he proves something that looks like housekeeping: any well-formed formula longer than one symbol splits into an antecedent and a consequent in exactly one way. The proof is a page of bracket counting — walk the string left to right, add one for each opening bracket and subtract one for each closing one, and show by induction that only the final bracket ever reaches zero, which pins where the split must fall. Nothing in it is deep. What matters is where he puts it. It comes immediately before the definition of a formula's truth-value, and when he states that the value of a formula under an assignment is unique, the justification he gives is that theorem and nothing else.

The dependency is worth spelling out because it is easy to have backwards. The valuation rule is stated by cases on the form of the expression: this is what a variable is worth, this is what a constant is worth, this is what an implication is worth given what its two parts are worth. Read casually, that defines a function. It does not. It defines a relation between expressions and values, and the relation is single-valued only if every expression matches exactly one case in exactly one way. If a string could be read as an implication with two different splits, the rule would assign it a value along each reading, the two values could differ, and there would be no such thing as *the* value. The recursion would still terminate, still be effective, still produce answers — different ones, depending on how you happened to look at the expression. Unambiguity is not a precondition for the definition being convenient. It is a precondition for the definition existing.

The engineering version of this is everywhere and is usually treated as a style issue. A grammar with a shift-reduce conflict is not merely awkward to parse; every downstream pass defined by structural recursion over its trees is defined only up to whichever tree the parser happened to build, and the language has no semantics independent of the parser implementation. A wire format where a byte sequence admits two parses does not have an interoperability inconvenience, it has two meanings, and the security literature is largely a record of what happens when a validator picks one and the consumer picks the other. A configuration merge whose result depends on file ordering has no defined result. A data model where one state is reachable by two different histories cannot support any property proved by induction on history. In each case the visible symptom is disagreement between implementations, and the actual defect is that the specification never denoted a function.

The practice that follows is to make the unambiguity claim explicit and to discharge it before, not after, building anything by recursion on the structure. State the claim as its own proposition — every value of this type has exactly one top-level decomposition, every accepted input has exactly one parse, every state has exactly one canonical construction — and prove it, or arrange the representation so that it is trivial. Fully parenthesized syntax, tagged unions, length-prefixed encodings, and constructors that are the only way to build a value are all the same move: pay a little in surface ugliness to buy a decomposition theorem for free. Church's own primitive notation is uniformly bracketed and correspondingly unpleasant to read, and he layers a whole apparatus of dropped brackets and precedence on top of it for human consumption. That ordering is the point. The unambiguous form is what the definitions and proofs run on; the readable form is a presentation device sitting above it. Doing it the other way — designing the pleasant surface first and hoping a unique reading falls out — is how you end up with a language whose meaning is whatever the parser does.

**Source:** [Introduction to Mathematical Logic](../works/introduction-to-mathematical-logic.md) — the metatheorem in the section of further theorems of the propositional calculus asserting that a well-formed formula of more than one symbol has the form of an implication in one and only one way, proved by counting brackets left to right and showing that only the final bracket has number zero; together with the following section's definition of the value of a formula by recursion on its well-formed parts and its remark that the uniqueness of that value is a consequence of exactly that metatheorem.
