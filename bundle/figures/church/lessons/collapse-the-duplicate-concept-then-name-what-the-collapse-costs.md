# When a second theory would duplicate the first step for step, collapse the two concepts — then state the law the collapse breaks

Church makes the same reductive move three times in a few pages, and each time he shows his work. Sentences look like a different kind of thing from names, since their conspicuous use is to assert rather than to designate; he nonetheless treats them as names of a special sort. Classes look like a different kind of thing from one-place functions to truth-values; he identifies them. Relations look different from two-place ones; same treatment. In every case the justification is economy rather than discovery. He is explicit that the identification of sentences with names is not demonstrated, and that his reason for adopting it is that otherwise a theory of sentence-meaning would have to be built independently — a theory whose development would parallel the one already given so closely that the identification would end up suggesting itself anyway. Near-total duplication between two accounts is the diagnostic. If the second theory is going to recapitulate the first step for step, the second thing is a case of the first, and the honest response is to say so up front rather than maintain a distinction nothing rests on.

The discipline that makes this safe is the other half, and Church never omits it. Immediately after identifying classes with one-place truth-valued functions he states what the identification costs: the principle that two classes with the same members are the same class no longer holds outright. It holds only once the domain of applicability is also fixed, because that domain came along with the function and is now part of what a class is. The visible consequence is that there is not one empty class, there is one per domain — an emptiness is always emptiness-of-something, and the something has to be carried. He then does the thing that turns a concession into an argument: he names what the alternative would cost instead. A set theory that keeps unconditional extensionality gives up the guarantee that every predicate carves out a set. Some price is unavoidable here, since the naive notion that pays neither price is inconsistent. Knowing both bills is what makes the choice a decision.

So the pattern has two obligatory steps, and the second is where engineers fail. Unifying two concepts is almost always right when nothing observable distinguishes them, because every maintained distinction costs vocabulary, costs parallel machinery, and costs every future reader who has to learn which one applies. But a collapse never preserves every law both sides enjoyed. Something that used to hold unconditionally now holds only relative to information the merged notion drags along, and if that dependency is not written down at the moment of merging, it is discovered years later by whoever hits the case where the old law silently fails.

The transfer is direct. Merging two record types, treating a value and a nullary function as one thing, representing a class as a predicate, letting one abstraction serve two call sites that seemed to differ only cosmetically — all are the good move, and all of them relativize some equality or some identity that used to be absolute. The empty collection is the cleanest example a programmer already knows: once a container carries its element type, the empty one is not a single value but a family, and code that compares two emptinesses is asking a question that needs the type to answer. The rule to keep is that a unification is not finished when the two things become one. It is finished when you have written down which previously unconditional property now requires an extra parameter, and what the alternative design would have charged you instead.

**Source:** [Introduction to Mathematical Logic](../works/introduction-to-mathematical-logic.md) — the section on propositions and propositional functions, which argues for treating sentences as a species of name on grounds of unification rather than proof, identifies classes with one-place propositional functions because no purpose is served by the distinction, then states that this sacrifices unconditional extensionality of classes, forces emptiness to be relative to a range, and contrasts the opposite sacrifice made by Zermelo-style set theory.
