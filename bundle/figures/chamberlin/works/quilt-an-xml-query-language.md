description: Proposes Quilt, a query language that merges the document-transformation strengths of XML-QL with the path-navigation strengths of XPath/XQL, wrapped in FOR/LET/WHERE/RETURN clauses deliberately echoing SQL's SELECT/FROM/WHERE shape. The paper frames it as a deliberately small, implementable language rather than a maximalist design, meant to unify querying across XML documents, relational data exposed as XML, and other semi-structured sources. Quilt itself was never standardized, but it became the working design the W3C XML Query group adopted as the starting point for XQuery.
