# Let each level transform requests for the level below it, and never reach past a child

**Lesson:** In a nested structure where every level may be extended by parties who do not know each other, the routing discipline matters more than the individual behaviours. The rule worth adopting is that a request arriving at a component is handled by that component and, where the work belongs further down, is passed only to that component's immediate children — never to a grandchild, never to a sibling, never to anything the sender happened to have a reference to. Every level therefore sees exactly one incoming request and decides what set of outgoing requests it produces. Nothing routes around anybody.

Once the discipline is in place, handling stops being a special case per message and becomes a single kind of thing: a transformation from an incoming request to a set of outgoing ones, plus whatever local effect the level itself is responsible for. The degenerate case, where the outgoing set is a copy of the incoming request sent to each child, is plain delegation and covers most messages. The interesting cases are where the transformation is not the identity — where a level converts a request phrased in its own vocabulary into requests phrased in its children's, computing the parameters that only it knows. A level that owns a decomposition is precisely the level that knows how a change to the whole apportions into changes to the parts, and expressing that as a translation between request types puts the knowledge where it belongs and nowhere else.

Two things follow that are easy to miss. First, when a level needs to express something to its children for which no request type exists, it should introduce one rather than reaching for a shared vocabulary or widening an existing type. The new type is meaningful only between that level and its children, and defining it locally keeps it that way — a vocabulary is a coupling, and coupling should be as narrow as the relationship it serves. Second, recursive whole-structure operations become uniform once every level obeys the discipline: to duplicate a composite, send the duplicate request to each child, copy the local descriptor, and attach the returned children to it. There is no traversal code that knows the shape of the tree, because each level contributes only its own step. The same skeleton with the child requests omitted gives a shallow copy instead of a deep one, which is a useful reminder that the depth of such an operation is decided by whether the recursion is invoked, not by anything about the data.

The general form: in a layered or nested design, make "who may talk to whom" an explicit invariant rather than an emergent property, and make it as restrictive as parent-to-immediate-child. The restriction costs a few forwarding steps and buys the ability to insert, replace, or extend any level without auditing the rest, which is the only reason nesting was worth having.
