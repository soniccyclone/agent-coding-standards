description: The original language definition report for Modula-2, Wirth's successor to Pascal, introducing the module as a first-class unit of compilation with explicit export lists separating interface from implementation. It formalized separate compilation with compile-time type checking across module boundaries, a facility Pascal lacked, and added coroutine-based low-level facilities for systems programming. This report is the primary source for the language later popularized by the book "Programming in Modula-2"; that book itself was not found in a verifiably open edition, so this earlier technical report stands in as the public, citable definition of the language.
