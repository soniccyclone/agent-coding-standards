description: A short polemic arguing that software had grown bloated not because complexity demanded it but because cheap, fast hardware removed any economic pressure to keep programs small and disciplined — what later got named Wirth's law, that software gets slower faster than hardware gets faster. Wirth uses his own Oberon system, built by a small team in a fraction of the code of comparable commercial systems, as a working counterexample. The piece is less a technical paper than a design-values manifesto aimed at the software industry of the mid-1990s.
