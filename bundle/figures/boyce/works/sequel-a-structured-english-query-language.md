description: The first published design for SEQUEL, the query language Boyce and Chamberlin built directly on Codd's relational model, later renamed SQL by IBM after a trademark conflict. Its central move is replacing the predicate-calculus notation of earlier relational query proposals with English-keyword clauses aimed at non-programmers, while still mapping cleanly onto the underlying relational algebra. It is the direct textual ancestor of the query language that now runs on effectively every relational database.
