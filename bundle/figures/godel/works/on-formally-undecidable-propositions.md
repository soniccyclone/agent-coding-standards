description: Constructs, for any formal system rich enough to express elementary arithmetic and free of contradiction, a sentence that encodes its own unprovability within that system. Gödel builds this via an arithmetic coding of formulas and proofs (Gödel numbering) so that syntactic questions about provability become number-theoretic questions the system itself can state but not settle. The result establishes that no fixed, consistent, effectively axiomatized system can be both complete and capable of proving its own consistency — a hard boundary on formal/mechanical reasoning that predates and shapes every later model of computation.
