# An adaptive process that is cheap overall must pass through states worth keeping, so you can stop adapting and harvest one

**Lesson:** A bound on the total cost of a self-organizing process looks like a statement about cost and nothing else. This paper extracts a statement about *configurations* from it. The reasoning is that if the process is cheap over a long run, and its cost at each moment is determined by the state it is in, then the states it occupies cannot mostly be bad ones — so a state sampled from the run at a uniformly random time is, in expectation, a good state. The paper turns this into a theorem: run the adaptive process for a while, stop adapting at a randomly chosen moment, and freeze the current configuration as a static structure. With enough accesses first, that frozen configuration is within a constant factor of the best static configuration for the access distribution, and the argument uses no property of the mechanism beyond its amortized efficiency, so it applies to any self-organizing structure with such a bound.

The transferable idea is that an amortized guarantee is secretly a guarantee about the quality of the states visited, and that opens a design option people rarely consider: run the adaptive thing to learn a configuration, then keep the configuration and turn off the adaptation. The learning phase pays for itself under the original bound; the frozen phase then delivers the learned benefit while shedding everything the adaptivity cost — no mutation on the read path, no per-access restructuring, no loss of shareability. This is exactly the shape of profile-guided compilation, of building an index from observed query patterns and then serving it read-only, of warming a layout and shipping it. What the theorem supplies is the missing justification for why the harvested configuration should be any good, and it makes that justification depend on a property you may already have proven for other reasons.

Two limits are stated with the result and both matter more in practice than the theorem does. The guarantee is in expectation over when you stopped, so a particular freeze can land on an unrepresentative state — a real risk, since a single bad frozen layout has no mechanism left to recover from itself. And the frozen structure is tuned to the distribution it observed, so it decays exactly to the extent that usage shifts, with no adaptivity remaining to notice. The authors conclude the technique is practical mainly where the stationarity assumption genuinely holds. That is the right shape for the decision: freezing converts a self-correcting system into one whose quality is fixed at a moment in time, so it is a good trade when the workload is stable and a slow-motion failure when it is not, and the choice should be made on the stability of the workload rather than on the elegance of the result.

**Source:** [Self-Adjusting Binary Search Trees](../works/self-adjusting-binary-search-trees.md) — the second form of conditional restructuring, in which restructuring is performed for the first randomly-chosen number of accesses and then stopped permanently, together with its stated intuition that an amortized-efficient structure ought to have a good average state; the theorem bounding the expected average access time of the resulting static tree under fixed independent access probabilities; the remark that the only property of the structure used in the proof is its amortized efficiency, so the result generalizes to any self-adjusting structure with an amortized bound, including the move-to-front list rule; and the two stated drawbacks that the resulting static structure has a small chance of being inefficient and that it loses its efficiency if the access pattern changes.
