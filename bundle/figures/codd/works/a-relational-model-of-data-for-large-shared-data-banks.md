description: The founding paper of relational database theory, proposing that data be stored as simple tables (relations) rather than the pointer-laden hierarchical or network structures common at the time. Codd argues that separating logical data structure from physical storage detail lets application programs stay stable even as storage layout changes, and sketches a small algebra of operators for querying and manipulating relations. It set the terms nearly all subsequent database work reacted to or built on.
