# Edgar F. Codd

**Dates:** 1923-2003. IBM San Jose Research Laboratory mathematician and computer scientist; British-born, RAF veteran.

## Why a candidate
Originated the relational model itself — the paper that reduces data management to a small set of algebraic operators over relations, the archetype of the "irreducible primitives" standard this project is vetting for. Strongest primitive-grounded candidate in this subdomain.

## Top 10 most influential works
1. "A Relational Model of Data for Large Shared Data Banks" (1970, CACM) — `public` (widely self-archived)
2. "Derivability, Redundancy, and Consistency of Relations Stored in Large Data Banks" (1969, IBM Research Report) — `public` (IBM tech report)
3. Codd's 12 Rules ("Is Your DBMS Really Relational?", 1985, ComputerWorld) — `public` (widely reproduced)
4. "A Data Base Sublanguage Founded on the Relational Calculus" (1971, SIGFIDET) — `paywalled`
5. "Further Normalization of the Data Base Relational Model" (1972, book chapter) — `uncertain`
6. "Relational Completeness of Data Base Sublanguages" (1972) — `uncertain`
7. "Extending the Database Relational Model to Capture More Meaning" (RM/T, 1979, ACM TODS) — `paywalled`
8. "Recent Investigations in Relational Data Base Systems" (1974, IFIP) — `uncertain`
9. "Normalized Data Base Structure: A Brief Tutorial" (1971) — `paywalled`
10. *The Relational Model for Database Management: Version 2* (1990, book) — `paywalled`
