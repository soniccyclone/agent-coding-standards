It proposes treating the meaning of a program as a mathematical function mapping inputs to outputs, defined without reference to any particular machine or execution model, and it tackles the hard technical snag of that approach — how to give a well-founded mathematical meaning to recursive and self-referential definitions. The domain-theoretic machinery Scott built to solve that problem became the standard mathematical foundation for language semantics for decades afterward.
