description: Argues that reliability, security, and delivery-guarantee functions usually cannot be correctly implemented by a low-level communication or storage layer alone, because that layer lacks the application-specific knowledge needed to finish the job — so those functions belong at the endpoints, with lower layers earning their keep only as performance optimizations. Walks through careful file transfer, encryption, duplicate suppression, and delivery acknowledgement as worked examples, then extends the reasoning past networking to file systems, RISC instruction sets, and "open" operating systems. One of the most cited general-architecture arguments in computer science for deciding which layer of a system should own a given piece of functionality.
