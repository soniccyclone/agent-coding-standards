description: Valiant reframes machine learning as a question in computational complexity — a concept class is "learnable" if an algorithm can, from a polynomial number of random labeled examples and in polynomial time, produce a hypothesis that is probably approximately correct (PAC). Working through concrete concept classes such as conjunctions of Boolean literals, he shows which admit efficient learning procedures under this definition and which don't. The paper turned "can this be learned" into a question with the same rigor as "can this be computed," founding computational learning theory as a field.
