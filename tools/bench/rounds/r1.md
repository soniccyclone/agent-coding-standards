Build a persistent job queue as a Python library in this directory.

A job has a payload (arbitrary JSON-serialisable data) and moves through states.
Queue contents must survive process restart.

So that other people's code can use this, expose exactly these names from a
module called `jobqueue`:

    Queue(path)          construct against a storage location of your choosing
    q.enqueue(payload)   returns a job id
    q.claim()            returns an object with .id and .payload, or None if
                         nothing is available
    q.done(job_id)
    q.fail(job_id)

How you store jobs, what the states are, and everything about the internal
design is yours to decide.

Include tests and a short README describing the public API. The library itself
must use only the Python standard library; tests may use pytest.
